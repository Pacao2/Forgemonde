# v14oct — la grande refonte visuelle

Publiée le 14 octobre 2026.

## ✨ Nouveautés

### Carte vivante
- **Anneaux d'événements animés** : pulsation dorée sur votre faction, anneaux rouges décalés sur celles qui réagissent — chacune « complote » à son rythme
- **Onde de choc** sur les événements majeurs : une onde circulaire se propage depuis le lieu de l'action
- **Lueur au sol** sous la faction active
- Tout désactivable via Réglages → Animations : réduit

### Zoom cinématique
- Après chaque action, la caméra zoome sur la zone concernée
- Bouton **« 🎯 Zoomer sur la zone »** dans chaque entrée de la chronique

### Interface
- **Refonte mobile** : barre d'onglets repensée, champ d'action toujours visible, cibles tactiles 44 px, fin du zoom automatique iOS
- **Écran allégé** : panneaux repliés par défaut, chronique limitée aux 8 derniers tours (extensible)
- **Pastille moteur** dans le HUD : « ⚙ Règles » ou « 🤖 IA : modèle », cliquable
- **Nouvel onglet Journal** : l'historique complet des versions dans le jeu

### Partage
- **Panneau « 📣 Partager ma partie »** : post prêt pour Discord/Reddit + image de carte avec bandeau doré
- **Retours repensés** : « Copier mon retour » + ouverture directe de Discord/Reddit
- **Balises Open Graph** : les liens partagés affichent titre et image

## 🐛 Corrections
