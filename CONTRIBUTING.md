# Contribuer à Forgemonde

Merci de vouloir aider ! 🙏

## Signaler un bug

Le plus efficace :
1. Dans le jeu : onglet **Retours** → **« Copier mon retour »**
2. Ouvrez une [issue](https://github.com/Pacao2/Forgemonde/issues/new/choose) et collez le rapport

## Suggérer une amélioration

Ouvrez une issue avec le template 💡 — plus le contexte est précis (situation en jeu, ce que vous attendiez), plus c'est actionnable.

## Tester

Le jeu est en test public. Jouer 10 tours et raconter ce qui vous a fait fermer l'onglet est déjà une contribution majeure.

## Code

Le jeu est un fichier `index.html` autonome. Si vous proposez une PR :
- gardez le fichier unique et sans dépendance externe
- vérifiez que le jeu fonctionne **sans IA ni réseau**
- décrivez le changement dans le message de commit
